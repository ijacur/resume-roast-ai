## ⚡ Core Features
1. **Free ATS Diagnostic Roast**: Scans resumes for passive verbs, lack of metrics, and keyword matching.
2. **Google XYZ Bullet Point Formula**: Rewrites weak bullet points into high-impact quantified achievements (*"Accomplished [X] by doing [Y] as measured by [Z]"*).
3. **Multi-Tier Instant Checkout**:
   - **Tier 1 — Essential ATS Rewrite ($4.99)**: Rewritten bullets, executive summary, cold InMail pitch.
   - **Tier 2 — VIP Career Accelerator ($7.99)**: Tier 1 + Tailored Cover Letter + STAR Interview Prep Cheatsheet + 1-click Markdown exporter.
4. **Programmatic SEO Role Hubs**: Targeted landing pages for `/roles/software-engineer.html`, `/roles/product-manager.html`, `/roles/data-scientist.html`, `/roles/devops-cloud-architect.html`.
5. **Instant Crypto & Card Gateway**: Built-in support for Apple Pay, Visa/Mastercard, and USDT (TRC-20) / TON.
